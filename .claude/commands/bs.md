# /bs — Bootstrap Reload

Re-run the full session startup sequence mid-conversation. Use when context feels stale or after a long break.

## Workflow

1. Read persona file (`SOUL.md` or relevant `personas/*.md`)
2. Read `workspace/USER.md`
3. Read `workspace/MEMORY.md`
4. Read today's + yesterday's `workspace/memory/YYYY-MM-DD.md`
5. Read `workspace/TOOLS.md`
6. Greet Boss in persona voice, confirm you're caught up
